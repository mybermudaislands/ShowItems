## ItemRack (GPL-3.0)

According to comments in the source code (`ShowItems/Window.lua`, `ShowItems/Flyout.lua`), the following textures in `ShowItems/Textures/` come from the ItemRack addon, which is licensed under GPL-3.0:

| File | Origin according to the code comments |
|---|---|
| `ItemRackButtons.blp` | The ItemRack button sheet. |
| `ItemRackOptTabs.tga` | The ItemRack options window tab textures. |
| `ShowItemsLock.tga` | Closed and open padlock drawn from the ItemRack button sheet (the open padlock is the closed one with the shackle raised). |

The code comments in `ShowItems/Window.lua` also state that the window layout follows the ItemRack options window. Several other comments say that widgets and the Sets tab are made in the look of ItemRack. These comments describe the visual style. This repository does not record whether any ItemRack source code was copied.
