# ShowItems

ShowItems это аддон для World of Warcraft (клиенты эры Classic, интерфейс 16001), который отслеживает слоты экипировки в небольших перемещаемых окнах. Окно отслеживания показывает предмет, надетый в слоте, позволяет использовать его одним щелчком и выводит список предметов из ваших сумок, подходящих для этого слота, чтобы их можно было быстро поменять. Аддон также сохраняет наборы экипировки и раскладки окон отдельно для каждого персонажа.

[English version](README.md)

## Возможности

- **Окна отслеживания.** Можно отслеживать любой из 19 слотов экипировки. Для каждого отслеживаемого слота создаётся небольшое окно с иконкой предмета и перезарядкой. Левый щелчок использует предмет. Окно можно перетаскивать.
- **Магнит.** Окна прилипают друг к другу, если бросить их рядом. Брошенное окно принимает размер того, к которому прилипло. Удерживайте Ctrl при перетаскивании, чтобы вытащить одно окно из группы.
- **Меню предметов из сумок.** Наведите курсор на окно отслеживания, и появится список предметов из ваших сумок, подходящих для этого слота. Щелчок по предмету надевает его. В бою предмет ставится в очередь и надевается после боя, а на окне показывается его маленькая картинка.
- **Меню окна.** Правый щелчок по окну отслеживания открывает тот же список предметов и кнопки: заблокировать окна, изменить размер группы, отслеживать или не отслеживать слоты.
- **Меню в окне персонажа.** Когда курсор находится над слотом в окне персонажа, рядом со слотом показываются предметы из сумок, подходящие для него. У каждого предмета есть звезда: предметы со звездой (избранные) стоят в списке первыми. Избранный предмет, которого нет ни в сумках, ни на персонаже, забывается через сутки. У меню есть необязательное мерцающее свечение.
- **Короткие подсказки предметов.** Меню показывают короткую подсказку с названием предмета и его характеристиками вместо полной подсказки с окнами сравнения.
- **Наборы.** Выберите слоты, введите имя и нажмите Save, чтобы сохранить надетые предметы (или предметы, выбранные вами из сумок). Набор надевается из сумок одним щелчком, или на него можно назначить клавишу. Предметы берутся только из сумок, никогда из банка. В бою клавиша набора меняет только оружие.
- **Профили.** Сохраните раскладку окон (отслеживаемые слоты, положение, размеры, интервал, группы, прозрачность, блокировку и назначения клавиш) под именем и загрузите её позже. Аддон хранит последние 5 автоматических снимков (делаются перед сбросом, перед загрузкой профиля и перед восстановлением снимка). Наборы в профили не входят.
- **Назначение клавиш.** Назначьте клавишу на использование отслеживаемого слота или на надевание набора. Назначения применяются как override-привязки, поэтому ваши собственные сохранённые привязки клавиш никогда не меняются.
- **Настройки.** Блокировка окон, свечение, включение и выключение аддона, интервал между окнами, прозрачность, размер окон, общий размер и сброс.
- **Кнопка у миникарты и пункт в меню аддонов (addon compartment).**
- Настройки хранятся отдельно для каждого персонажа.

## Установка

1. Скачайте последний zip-архив релиза на странице [Releases](../../releases).
2. Распакуйте его так, чтобы папка `ShowItems` оказалась внутри вашей папки AddOns (в папке должен лежать файл `ShowItems.toc`).
3. Запустите игру, или введите `/reload`, если она уже запущена.

## Как пользоваться

- **Начать или прекратить отслеживание слота:** в окне персонажа щёлкните слот правой кнопкой с зажатым Ctrl, чтобы выбрать его. Ctrl+Shift+правый щелчок по нескольким слотам выбирает их все. Затем выберите Track или Untrack в открывшемся меню. Также можно нажать кнопку с глазом в меню окна отслеживания и щёлкать слоты там.
- **Использовать предмет:** левый щелчок по окну отслеживания.
- **Перемещать окна:** перетаскивайте их. Рядом друг с другом окна прилипают. Ctrl+перетаскивание двигает одно окно отдельно.
- **Поменять предмет:** наведите курсор на окно отслеживания или на слот в окне персонажа и щёлкните предмет в списке.
- **Изменить размер:** нажмите кнопку изменения размера в меню правого щелчка по окну и потяните за треугольник, который появится в углу группы. На вкладке Settings также есть регуляторы размера, интервала и прозрачности.
- **Вкладка Sets:** щёлкайте слоты вокруг панели, чтобы выбрать их, введите имя и нажмите Save. Правый щелчок по слоту позволяет выбрать для него предмет из сумок. Equip надевает набор из сумок, Bind Key назначает клавишу, Delete удаляет набор.
- **Справка:** наведите курсор на маленькую надпись "SI" в левом верхнем углу окна ShowItems, чтобы увидеть короткую подсказку.

## Кнопка у миникарты

- Левый щелчок: список наборов (щелчок по набору надевает его)
- Правый щелчок: настройки
- Shift+левый щелчок: включить или выключить аддон (серая иконка означает, что аддон выключен)
- Перетаскивание: двигает кнопку вокруг миникарты

В меню аддонов (addon compartment, свёрнутое меню аддонов) левый щелчок открывает настройки, а правый включает или выключает аддон.

## Слэш-команды

- `/si` или `/showitems`: открыть окно на последней использованной вкладке
- `/si sets`: открыть вкладку Sets
- `/si profiles`: открыть вкладку Profiles
- `/si help`: показать список команд
- `/si reset`: перестать отслеживать все слоты и сбросить положение, размеры и назначения клавиш (сначала делается снимок, см. Профили)

## Известные ограничения

- Окна отслеживания это защищённые (secure) фреймы, поэтому в бою их нельзя создавать, двигать, изменять в размере или менять. Изменения применяются после боя.
- Смена экипировки из кода аддонов в бою на этом клиенте заблокирована. Наборы нельзя надевать в бою, кроме того что клавиша набора в бою меняет оружие (правая рука, левая рука, дальний бой).
- Предметы берутся только из сумок, никогда из банка.
- Аддон разрабатывался и проверялся для клиента WoW "Forever" (интерфейс 16001). Другие клиенты не проверялись.
